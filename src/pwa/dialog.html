IPHONE / IPAD

Install with Safari

  1. Open the game's live link in Safari.
  2. Open Share and choose Add to Home Screen.
  3. Turn on Open as Web App if shown, then tap Add.

Missing the option? Open Safari itself rather than an embedded school, email or social-app browser. School device restrictions may prevent installation.

ANDROID

Install with Chrome

  1. Open the game's live link in Chrome.
  2. Tap Install app here when available, or open Chrome's three-dot menu.
  3. Choose Install and create shortcut → Install. Some versions say Add to home screen → Install. Confirm the installation.

A Chromebook or desktop Chrome/Edge may also offer an install icon in the address bar or browser menu.

Before you go offline

Launch the home-screen app once while connected. Wait until it says OFFLINE READY, then test by turning off Wi-Fi/mobile data and reopening it. All current game questions and diagrams are saved together.

Your work stays with you

No accounts, cloud sync or leaderboard. Use Export Progress on the home page before switching from a downloaded file to the website, or moving between browsers, the installed app and another device. Use Import Progress in the destination; it replaces that copy's saved progress.
